Jonga Kopi Website
---
This repository contains the source code for Jonga Kopi Web, a modern, responsive website designed for a coffee shop and café. The project showcases the café's branding, product menu, business hours, and seamless user experience, crafted to bridge the gap between traditional coffee culture and digital convenience.

📌 Project Status: ✅ Completed (Maintained)
The initial core features and front-end interface have been successfully deployed. This repository will be continuously updated for code optimisations, performance enhancements, and future additions like an interactive ordering system.

🚀 Key Features & Layout
The website incorporates several essential components suited for a contemporary café presence:

Interactive Homepage: A visually engaging landing section that introduces the Jonga Kopi brand concept and current promotions.

Digital Café Menu: A categorised display of beverages (coffees, non-coffees) and pastries, complete with pricing and detailed descriptions.

About Us Section: Narrative details about the origin of Jonga Kopi’s beans, roasting process, and philosophy.

Contact & Location Finder: Integrated contact information, operating hours, and a map layout to help customers easily locate the physical shop.

Responsive Layout: Optimised layout for multiple devices, ensuring an outstanding viewing experience across mobile phones, tablets, and desktop computers.

🛠️ Technologies & Tools Used
Front-end Structure: HTML5 & CSS3 (Custom styling with emphasis on warm, café-inspired colour palettes).

Interactivity: JavaScript (For smooth scrolling, navigation bars, and dynamic components).

Design & IDE: Visual Studio Code.

Version Control: Git & GitHub.

💻 How to Run and Preview the Project Locally
Prerequisites
To view this project, all you need is a modern web browser (such as Google Chrome, Mozilla Firefox, or Microsoft Edge).

Steps to Launch
Clone this repository to your local machine:

```Bash
git clone https://github.com/Alimurtadlo16/jonga_kopi_web.git
```

Navigate into the project folder:

```Bash
cd jonga_kopi_web
```

Open the main file (index.html) in your preferred web browser:

Double-click the index.html file in your file explorer, or

Use a code editor extension like Live Server in VS Code for a real-time preview.
